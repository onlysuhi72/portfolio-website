My Portfolio

A responsive personal portfolio website showcasing my background, skills, projects, education, certifications, and contact information as an aspiring web developer.

Features

The website features a responsive design optimized for desktop, tablet, and mobile devices. It includes a hero section with a personal introduction, an about section, a skills
and technologies section, and a featured projects section. It also includes an education, certifications, and experience timeline, a downloadable resume, and a contact form integrated
with EmailJS. Additional features include smooth scrolling navigation, a scroll progress indicator, custom cursor interactions, scroll-triggered reveal animations, and an accessible
skip-to-content link.

Built With

The portfolio was built using React and Vite, with JavaScript, HTML5, and CSS3 for the core development. EmailJS is used for the contact form, while Tailwind CSS is configured for
styling and utility classes.

Technologies

The project uses HTML, CSS, JavaScript, React, PHP, SQL, Vite, Tailwind CSS, Git, and GitHub.
